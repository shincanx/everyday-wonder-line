Entry for the [make.fun bounty "Everyday Wonder, Two Days to Find the Line"](https://make.fun/bounty/u-pangg7-everyday-wonder-two-days-to-find-the-line-970432d3) — a single sentence, at most 200 characters, that makes a small everyday moment strange and new: a lift door opening on a stranger's song, and the pause it leaves behind.

## Run

```sh
python3 main.py
```

Writes the sentence to `/output/entry.txt` and prints it to stdout. No network, no dependencies, deterministic.
